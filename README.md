# Ecommerce SQL Data Analysis

## Overview

This project demonstrates SQL-based data analysis using an Ecommerce dataset. The objective of this project is to extract meaningful business insights using SQL queries, aggregation functions, subqueries, views, and indexing techniques.

---

## Objectives

* Analyze ecommerce sales data
* Practice SQL querying techniques
* Generate business insights from structured data
* Perform filtering, grouping, and aggregation operations
* Understand database optimization concepts

## Queries Performed

### 1. Basic Data Selection

Retrieved records from the ecommerce dataset using SELECT statements.

### 2. Filtering Data

Used WHERE clause to filter transactions based on quantity and pricing conditions.

### 3. Aggregation Analysis

Calculated:

* Total quantity sold
* Average product price
* Country-wise sales analysis

### 4. Product Performance Analysis

Identified top-selling products based on total sales quantity.

### 5. Subqueries

Used nested queries to analyze products with pricing above average values.

### 6. View Creation

Created SQL views for reusable analysis and reporting.

### 7. NULL Value Handling

Analyzed missing customer records using IS NULL conditions.

### 8. Query Optimization

Implemented indexes to improve query performance.

---

## Business Insights

* Certain countries contributed significantly higher sales volumes.
* A limited number of products generated most revenue.
* Average pricing analysis helped identify premium products.
* Missing customer records highlighted incomplete transaction information.
